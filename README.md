# BioFarm — Pharmacy Landing Page

A clean, professional landing page for a pharmacy chain. Product catalogue, prescription upload flow, service grid, and multi-branch location info.

## Features

- **Product catalogue** — OTC medications, vitamins, cosmetics with search and categories
- **Prescription upload** — file upload CTA with confirmation flow
- **Services grid** — vaccination, blood pressure check, consultation, delivery
- **3 branch locations** — address, hours, phone per branch
- **Pharmacist team** — staff profiles with credentials
- **Health articles** — blog preview section
- **Mobile navigation** — hamburger menu with emergency contact prominent

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
